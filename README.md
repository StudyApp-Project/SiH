# 🚀 EduWrap — All-in-One Collaborative Study Workspace

EduWrap is a modern, frontend-based collaborative learning platform designed for college students to study together in a unified digital environment.

It combines multiple learning tools—notes, chat, flashcards, quizzes, and live study sessions—into a single seamless interface, eliminating the need to switch between different apps.

---

## 🎯 Project Objective

The goal of EduWrap is to simulate a real-time, interactive study platform using only frontend technologies. The application focuses on delivering a production-like user experience with dynamic UI, smooth interactions, and system-level design.

---

## ✨ Key Features

- 📚 Unified Workspace  
  Access notes, chat, files, and collaboration tools in one place

- 💬 Real-Time Chat (Simulated)  
  Instant messaging with typing indicators and message updates

- 📝 Collaborative Notes Editor  
  Structured note-taking with auto-save functionality

- 🧠 Flashcards System  
  Create and study decks with interactive card flipping

- 🧪 Quiz System  
  Attempt quizzes with timer and instant feedback

- 🎥 Study Room + Video Call UI  
  Simulated group study environment with integrated tools

- 📂 File Sharing (Simulated)  
  Upload and access resources within study rooms

- 🏆 Gamification  
  XP, streaks, and progress tracking

---

## 🧠 Core Concept

EduWrap is built around the idea of a:

> “Connected Workspace System”

Unlike traditional apps, tools are not isolated.  
Chat, notes, and resources remain accessible across different screens, creating a seamless and continuous learning experience.

## ⚙️ Tech Stack

| Layer        | Technology        |
|-------------|------------------|
| Frontend    | React (Vite)     |
| Routing     | React Router     |
| Styling     | Tailwind CSS     |
| Animations  | Framer Motion    |
| Icons       | Lucide React     |
| State Mgmt  | Context API      |
| Storage     | localStorage     |

---

## ⚠️ Important Note

This is a frontend-only prototype built as part of a capstone project.

- No backend is used  
- No real database  
- No real-time servers  

All dynamic behavior (chat, AI, file upload, etc.) is simulated using React state and localStorage.
